# Overview

As a software engineer looking to deepen my skills beyond the languages I already know, I chose to use this module to learn TypeScript. TypeScript is a strongly typed superset of JavaScript that compiles down to plain JavaScript, and it is widely used in modern web and application development for catching errors early and making large codebases easier to maintain.

For this Hello World assignment, I wrote a small TypeScript program that prints a greeting to the console and previews a feature of the larger Anime Tracker & Recommendation App I plan to build during this module. The program defines an `Anime` interface, stores a small watchlist of anime with genres and ratings, prints the list to the console, and then recommends the highest-rated anime from the list.

The purpose of this software is to demonstrate that I can set up a working TypeScript development environment, write and compile TypeScript code, and run it successfully from the command line.

[Software Demo Video](https://www.youtube.com/)

# Development Environment

To build and run this software, I used the following tools:

* Visual Studio Code as my code editor
* Node.js (v24) and npm to manage packages and run the compiled JavaScript
* The TypeScript compiler (`tsc`) to compile TypeScript into JavaScript
* Git and GitHub for version control and publishing the code

The program was written in **TypeScript** and compiled to JavaScript using the TypeScript compiler before being executed with Node.js.
